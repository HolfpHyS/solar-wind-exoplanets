# Solar Wind Exoplanets

![Солнечный ветер, экзопланета и ML-ретривал](assets/solar-wind-exoplanet-ml.png)

Репозиторий посвящён восстановлению физических параметров атмосферы экзопланеты по профилю поглощения в линии метастабильного гелия He I 10830 Å. Такие профили позволяют исследовать истечение атмосферы и её взаимодействие со звёздным ветром.

## Задача

По одномерному профилю поглощения модель оценивает:

- интенсивность XUV-излучения звезды (`XUVInt`);
- долю гелия (`Helium`);
- темп потери массы звёздным ветром (`Msw`);
- бинарный режим `H2a`.

Датасет рассчитан с помощью глобальной 3D-модели атмосферы экзопланеты. Научный контекст и использованные статьи собраны в [`papers/`](papers/README.md).

## Решение

1. Профиль интерполируется на единую сетку из 101 точки и преобразуется в двухканальный вход.
2. Ансамбль из пяти multi-head CNN обучается с winner-takes-all loss и формирует несколько совместных кандидатов `(XUVInt, Helium, Msw)`.
3. Ранкер использует PCA-признаки профиля и геометрию пула кандидатов, чтобы выбрать наиболее правдоподобные ответы.
4. Diversity-фильтр возвращает пять различных кандидатов, а отдельная голова классифицирует `H2a`.
5. В leakage-aware OOF-эксперименте ранкер обучается только на out-of-fold кандидатах.

На историческом development-наборе из 118 объектов OOF-ranker снизил top-1 XUV MAPE с **23.71%** до **19.12%**. Это улучшение single-answer ранжирования, но не результат на новом blind test; подробности и ограничения приведены в [`OOF_RANKER_REPORT.md`](OOF_RANKER_REPORT.md).

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install numpy torch scikit-learn scipy

python infer.py path/to/Absorption.dat
```

Скрипт загрузит готовые веса из [`checkpoints/`](checkpoints/) и выведет вероятность `H2a` и пять ранжированных наборов физических параметров.

Для повторного обучения базового ансамбля датасет `new_dataset_V3` должен находиться рядом с каталогом репозитория:

```bash
python train_and_save.py
```

## Структура

| Путь | Назначение |
|---|---|
| `infer.py` | инференс для одного профиля и расчёт валидационных метрик |
| `model_defs.py` | архитектуры CNN и ранкера |
| `train_and_save.py` | обучение базового ансамбля и сохранение весов |
| `run_oof_ranker_experiment.py` | leakage-aware OOF-эксперимент |
| `notebooks/` | исследовательские ноутбуки и варианты решения |
| `checkpoints/` | готовые модели и препроцессинг |
| `runs/` | артефакты воспроизводимых экспериментов |
| `papers/` | статьи и краткий путеводитель по литературе |
